# Mikrofon — Шумоподавление и улучшение звука для дешёвого микрофона

Лёгкий фоновый скрипт на Python, который в реальном времени очищает звук бюджетного микрофона (3.5 мм петлички, гарнитуры, дешёвые USB-микрофоны, встроенные микрофоны ноутбуков) и делает голос чистым, разборчивым и ровным по громкости — для **Discord, игр, Telegram, Zoom, OBS** и любых других программ.

## Что делает скрипт (6-ступенчатая обработка за ~10–20 мс)

1. **Предусиление (Pre-Gain)** — аккуратно поднимает уровень тихих микрофонов (настраивается автоматически под вашу модель).
2. **Срез низкочастотного гула (85 Гц) + подавление фона сети 50/60 Гц** — убирает электрическое гудение материнской платы, вибрации стола, шум кулеров ПК и «задувания» микрофона.
3. **Адаптивное спектральное шумоподавление (алгоритм Эфраима–Малаха + Minimum Statistics)** — в реальном времени вычитает постоянное шипение дешёвого тракта и шум комнаты, не превращая голос в «робота».
4. **Плавный голосовой Noise Gate / экспандер** — глушит паузы между словами, клики мыши/клавиатуры и дыхание без «проглатывания» окончаний слов.
5. **Студийный эквалайзер чёткости речи (Voice EQ)** — убирает «коробочный/бочковой» призвук на 280 Гц, добавляет разборчивость речи на 3.4 кГц и срезает высокочастотный песок выше 13.5 кГц.
6. **Компрессор и мягкий лимитер (Broadcast Compressor & Limiter)** — выравнивает громкость и защищает от перегруза/хрипа, если вы громко засмеялись или крикнули в игре.

Нагрузка на процессор — **менее 3–5% одного ядра**, автоматическое переподключение при перетыкании USB-микрофона или выходе ПК из сна.

## Быстрый старт на Windows (в 4 клика)

1. Убедитесь, что установлен **Python 3.10+** (с галочкой `Add python.exe to PATH`).
2. Чтобы передавать очищенный звук в Discord, игры и браузер, установите бесплатный виртуальный кабель **VB-Audio Virtual Cable**:
   - Скачайте с официального сайта: `https://vb-audio.com/Cable/`
   - Распакуйте архив и запустите `VBCABLE_Setup_x64.exe` **от имени администратора** -> нажмите *Install Driver*.
3. Запустите по очереди файлы в папке проекта:
   - **`1_install_windows.bat`** — один раз скачает библиотеки (`numpy`, `scipy`, `sounddevice`).
   - **`2_calibrate_and_test.bat`** — скрипт сам определит ваш микрофон, измерит фоновый шум, подберёт настройки в `config.json` и даст сразу послушать **5 секунд «ДО и ПОСЛЕ»**!
   - **`3_start_mikrofon.bat`** — запускает очистку микрофона в реальном времени.
   - **`4_enable_autostart.bat`** — включает **тихий автозапуск вместе с Windows** (работает всегда в фоне без чёрного окна консоли).
4. В настройках звука **Discord / Telegram / CS2 / Dota 2 / OBS** выберите в качестве микрофона:
   **`CABLE Output (VB-Audio Virtual Cable)`**.

## Быстрый старт на Linux (Ubuntu / Debian / Arch / Fedora)

На Linux сторонние драйверы не нужны — скрипт сам создаёт виртуальный микрофон через PipeWire / PulseAudio:

```bash
# 1. Системная библиотека PortAudio (если ещё не установлена)
sudo apt install -y libportaudio2 pulseaudio-utils   # Ubuntu / Debian

# 2. Виртуальное окружение и зависимости
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

# 3. Автокалибровка под ваш микрофон и тест «ДО / ПОСЛЕ»
.venv/bin/python mikrofon.py calibrate
.venv/bin/python mikrofon.py test

# 4. Создание виртуального микрофона и включение постоянной фоновой службы (systemd --user)
.venv/bin/python mikrofon.py setup-linux-mic
.venv/bin/python mikrofon.py autostart install
```

В Discord / играх / браузере выберите микрофон **`Mikrofon_Clean_Mic`**.

## Все команды CLI

```bash
# Показать все микрофоны и аудиоустройства в системе
python mikrofon.py devices

# Диагностика вашего микрофона (модель, частота, уровень шума, проверка гула 50/60 Гц)
python mikrofon.py diagnose

# Автонастройка под ваш конкретный микрофон (сохраняет профиль в config.json)
python mikrofon.py calibrate

# Записать 5 секунд голоса и сразу сравнить звучание ДО и ПОСЛЕ обработки
python mikrofon.py test

# Запуск в реальном времени (с выбором пресета: balanced, max_denoise, gaming, natural)
python mikrofon.py run --preset gaming

# Очистить готовый WAV-файл
python mikrofon.py process-file raw_voice.wav clean_voice.wav

# Управление фоновым автозапуском при старте системы (Windows / Linux / macOS)
python mikrofon.py autostart install
python mikrofon.py autostart status
python mikrofon.py autostart remove
```

## Готовые режимы (`--preset`)

| Пресет | Когда выбирать |
|---|---|
| `balanced` | Универсальный режим по умолчанию: убирает шум ПК и шипение, сохраняя естественный голос |
| `max_denoise` | Для очень шумных комнат, громких кулеров и фонящих 3.5 мм микрофонов с усилением +20/+30 дБ |
| `gaming` | Чёткая дикция для тиммейтов, отсечение кликов механической клавиатуры и плотная компрессия |
| `natural` | Мягкая деликатная чистка и лёгкий эквалайзер |
