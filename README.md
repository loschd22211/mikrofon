# Mikrofon 2.0 — ИИ-шумоподавление (RNNoise) + Анти-Бочка для дешёвого микрофона

Лёгкий фоновый скрипт на Python, который в реальном времени очищает звук бюджетного микрофона с помощью **нейросети Xiph RNNoise v0.2** и убирает **эффект «звука из бочки»** — для голосовых сообщений (**Telegram, ВК, WhatsApp**), **Discord, игр, Zoom и OBS**.

## Что делает версия 2.0

1. **Нейросеть RNNoise v0.2 (48 кГц Full-Band AI)** — вырезает нестационарные посторонние звуки: **скрип стула**, клики мыши, стук клавиатуры, кашель, шорохи, гул кулеров и шипение тракта.
2. **Подавление эха комнаты (Spectral Dereverb — «Анти-Бочка»)** — гасит гулкие отражения от стола и стен пустой комнаты, делая звук плотным и близким.
3. **Студийный эквалайзер против «бочки» (Anti-Barrel Broadcast EQ)**:
   - вырезает коробочный/бочковой резонанс на **380 Гц** (`-4.5..-6 дБ`) и гнусавость на **680 Гц**;
   - подчёркивает разборчивость речи на **3.8 кГц** и добавляет открытый студийный «воздух» выше **8.2 кГц** (`Air Shelf`);
   - не ставит узких режекторных фильтров поверх голосовых гармоник (100–200 Гц), сохраняя естественный тембр.
4. **Компрессор + плавный Noise Gate + мягкий лимитер** — выравнивает громкость и полностью глушит паузы между словами без «съедания» окончаний.
5. **Автоустановка виртуального микрофона (`install-cable`)** и **тихий автозапуск 24/7 (`autostart install`)**.

---

## Почему в ГС (Telegram / ВК) мог записываться старый звук?

Сам по себе Python-скрипт не может переписать физический драйвер вашего микрофона внутри ядра Windows — он создаёт поток очищенного звука и подаёт его в **виртуальный микрофон `CABLE Output (VB-Audio Virtual Cable)`**.

Поэтому чтобы в голосовых сообщениях шёл **уже очищенный звук (без скрипа стула и без бочки)**:
1. Должен быть установлен драйвер виртуального кабеля (`python mikrofon.py install-cable` скачает и запустит установщик сам).
2. В **Параметрах звука Windows -> Ввод** (или прямо в настройках микрофона **Telegram / Discord**) нужно выбрать микрофон:
   **`CABLE Output (VB-Audio Virtual Cable)`**.
   *(Сама программа `mikrofon.py` при этом автоматически продолжит брать звук с вашего настоящего физического микрофона.)*

## Быстрый запуск на Windows (через PowerShell)

В папке проекта достаточно запустить:
```powershell
powershell -ExecutionPolicy Bypass -File .\setup_windows.ps1
```
Или по шагам:
```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install --no-deps "pyrnnoise>=0.4.6"
.\.venv\Scripts\python.exe mikrofon.py install-cable
.\.venv\Scripts\python.exe mikrofon.py calibrate --preset anti_barrel
.\.venv\Scripts\python.exe mikrofon.py test
.\.venv\Scripts\python.exe mikrofon.py autostart install
.\.venv\Scripts\python.exe mikrofon.py run --preset anti_barrel
```

## Основные пресеты (`--preset`)

- `anti_barrel` — максимальное удаление эффекта «бочки» / эха комнаты + нейросеть против скрипа стула и шумов.
- `balanced` — универсальный студийный баланс по умолчанию.
- `max_denoise` — максимальное подавление сильного шума кулеров и посторонних звуков.
- `gaming` — плотный голос для игр, ГС и Discord.
- `natural` — мягкая деликатная чистка.
